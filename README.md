# seungwaakpan.com

Personal site. Static [Astro](https://astro.build) build served by nginx, deployed on Dokploy.

## Develop

```sh
pnpm install
pnpm dev        # http://localhost:4321
pnpm check      # type-check .astro/.ts files and content schemas
pnpm build      # check + static build to dist/ + copy check
pnpm test       # unit tests for the copy check
pnpm preview    # serve dist/ locally
```

No environment variables are needed.

## Editing content

All content is in the repo and validated at build time. A typo in a field name or a malformed date fails `pnpm build` with the file and field named.

| What | Where |
| --- | --- |
| Name, role (also the hero tagline), intros, socials, nav | `src/site.config.ts` |
| Projects (one file each; body = write-up) | `src/content/projects/<slug>.md` |
| Portrait (used for avatar + social card) | `src/assets/me.jpeg` |
| Resume PDF (linked in the header) | `public/resume.pdf`, generated by `pnpm resume` |

Schemas live in `src/content.config.ts`.

**Claims come from the CV.** The intro and project write-ups must trace to `~/Desktop/cv/SeungwaAkpan_CV.html` or to the project's public repo. Change the CV and the site together.

**Copy check:** `pnpm build` ends with `scripts/check-copy.mjs`, which reads the built HTML and fails on em dashes, banned stock words, links to private repos, and CV claims missing their qualifier (the cold start without "on staging", Qwen3-4B without "behind a flag", the task audit without "directed coding agents"). Add a rule there when a new claim needs a qualifier.

**Add a project:** copy any file in `src/content/projects/`, rename it (the filename is the URL slug), edit the frontmatter. Every project shows on the home page and /projects; `order` sorts them.

**Icons** (UI arrows, theme toggle) are [Lucide](https://lucide.dev/icons) via `@lucide/astro`, imported per component; size and stroke weight live in `ICON_PROPS` (`src/lib/icons.ts`).

**Resume:** edit the source at `~/Desktop/cv/SeungwaAkpan_CV.html`, then run `pnpm resume`. It renders a copy with the phone number stripped (and fails if one survives) to `public/resume.pdf`. Your source file is never changed.

## Deploy

`Dockerfile` builds the site and copies `dist/` into `nginx:alpine`. Config is in `nginx/`:

- `default.conf`: routing, 404 page, cache policy (hashed `/_astro/*` cached forever, HTML revalidated).
- `security-headers.conf`: included in every `location` that sets headers, because nginx drops inherited `add_header` directives otherwise.

```sh
docker build -t portfolio .
docker run --rm -p 8080:80 portfolio
```
